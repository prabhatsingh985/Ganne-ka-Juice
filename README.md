# 🎋 Ganna Baar (गन्ने का जूस)

> **"Ganna Baar"** — A viral, interactive roadside sugarcane juice tapri web toy with real hardware gyroscope physics and web audio synthesis. Inspired by Chai Baar.

## ✨ Features
- 📱 **Real Hardware Gyroscope & Accelerometer Physics**: Liquid tilts, sloshes, and rises realistically with your phone's physical movement.
- 🥤 **Tilt-to-Drink**: Tilt the phone back towards your mouth to take genuine sips!
- 🧃 **Authentic Mumbai Fluted Cutting Glass**: 36-node dynamic fluid spring mesh, frothy head (jhag), and rising bubbles.
- 📻 **Nostalgic Tapri Radio Jukebox**: 4 lo-fi 80s/90s Bollywood-style synthesized ambient tracks (FM 98.3, 92.7, 104.8).
- 🍋 **Flavors**: Asli Desi, Nimbu Pudina, and Shahi Kesar Badam.
- ⚡ **Zero External Dependencies**: Web Audio API synthesizer, Canvas 2D liquid renderer, pure Astro + Tailwind CSS.

## 🚀 Running Locally
```bash
npm install
npm run dev -- --host
```

## 📦 Building for Production / Vercel
```bash
npm run build
```
Deploy the generated `dist/` or connect the repo directly on [Vercel](https://vercel.com).
